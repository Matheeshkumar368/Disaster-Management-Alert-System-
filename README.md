## ≡ƒÄ» About the Project

**Disaster Management & Alert System** is a full-stack Java Spring Boot web application engineered to simulate a real-world emergency response command center. Built as part of the Infosys Springboard 6.0 Internship Program, the system provides role-based access control, JWT-secured REST APIs, real-time disaster monitoring, citizen reporting, responder task management, and admin-level alert broadcasting.

### Objectives

- Γ£à Enable **citizens** to register, report disasters, and receive emergency alerts
- Γ£à Enable **responders** to view assigned rescue tasks and update their status
- Γ£à Enable **admins** to monitor all disasters, broadcast alerts, and manage users
- Γ£à Secure all API endpoints with **JWT-based authentication**
- Γ£à Persist all data in a **MySQL relational database**
- Γ£à Deliver a full **multi-role web dashboard** accessible at `localhost:8080`
- Γ£à Provide structured **incident and citizen reporting** workflows

### Step 3 ΓÇö Set Up MySQL Database

Open MySQL and run:

```sql
CREATE DATABASE disaster_management;
```

Then run the provided setup script:

```bash
mysql -u root -p disaster_management < DATABASE_SETUP.sql
```

### Step 4 ΓÇö Configure Database Credentials

Open `src/main/resources/application.properties` and update:

```properties
spring.datasource.url=jdbc:mysql://localhost:3306/disaster_management
spring.datasource.username=root
spring.datasource.password=your_mysql_password
```

> Alternatively, set environment variables `DB_USERNAME` and `DB_PASSWORD` ΓÇö the app reads them automatically.
